# ☕ Little Snowflake Coffee

Sitio web de una cafetería ficticia de especialidad, con una estética cálida, acogedora y rústica. Busca transmitir la experiencia de disfrutar un buen café y productos de pastelería artesanal en un ambiente agradable.

## 📌 Descripción del proyecto

**Little Snowflake Coffee** Presenta los productos destacados de la cafetería, su historia, reseñas de clientes y un formulario de contacto.

El diseño está inspirado en los tonos tierra, la madera y los espacios acogedores, priorizando una experiencia de navegación sencilla, clara y adaptable a distintos dispositivos.

## ✨ Funcionalidades

- Navegación entre las diferentes secciones del sitio.
- Presentación de productos mediante tarjetas con imágenes, descripciones y precios.
- Sección institucional con información sobre la cafetería.
- Sección de reseñas demostrativas.
- Formulario de contacto con campos validados mediante HTML.
- Diseño responsive para computadoras, tablets y celulares.
- Imágenes ilustrativas para acompañar el contenido.

## 🛠️ Tecnologías utilizadas

- **HTML** estructura y contenido semántico del sitio.
- **CSS** estilos visuales, diseño responsive, Flexbox y Grid.
- **Google Fonts** tipografías Playfair Display y DM Sans.
- **Formspree** servicio previsto para gestionar los mensajes del formulario de contacto.

## 🚀 Cómo visualizar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador web.

## 📱 Diseño responsive

El sitio se adapta a diferentes tamaños de pantalla mediante media queries y herramientas de diseño como Flexbox y CSS Grid, para facilitar la navegación desde computadoras, tablets y dispositivos móviles.

## 📬 Contacto

El sitio incluye un formulario de contacto diseñado para que los visitantes puedan enviar consultas o sugerencias. Para habilitar el envío de mensajes, es necesario configurar el formulario con una dirección válida de Formspree.
